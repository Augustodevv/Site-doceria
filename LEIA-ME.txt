===============================================================
CERES BRIGADEIROS — PACOTE DO SITE (duas versões)
===============================================================
Repositório: https://github.com/augusto0108/Site-doceria

Este pacote tem o site completo em duas versões. Escolha UMA:

---------------------------------------------------------------
1) VERSÃO PRONTA — não precisa instalar nada (RECOMENDADA)
---------------------------------------------------------------
Abra o arquivo:   site-estatico/index.html   (duplo clique)

Funciona direto no navegador, offline, com todas as funções:
filtros do cardápio, carrinho, finalizar no WhatsApp,
"Monte seu Bolo", calculadora de festas e formulário de contato.

---------------------------------------------------------------
2) VERSÃO REACT (precisa do Node.js instalado)
---------------------------------------------------------------
Abra o terminal na pasta site-react e digite:

    npm install
    npm run dev

Depois abra no navegador:  http://localhost:5173

Para versão de produção já compilada, use um servidor local na
pasta site-react/dist (ex.: "npx serve dist").

===============================================================
ERROS MAIS COMUNS (e como resolver)
===============================================================

✔ "Abri o site-react/index.html e deu tela branca / erro de arquivo"
   → Isso é esperado. A versão React NÃO roda com duplo clique,
     porque o navegador bloqueia arquivos .js modulares em file://.
     Use a versão 1 (site-estatico) ou rode "npm run dev".

✔ "npm não é reconhecido / erro ao instalar"
   → Instale o Node.js em https://nodejs.org (versão LTS) e
     reabra o terminal.

✔ "Cliquei em "Finalizar no WhatsApp" e não abriu nada"
   → O navegador bloqueou o pop-up. Clique no ícone de pop-up
     na barra de endereço e escolha "Sempre permitir", ou use o
     botão flutuante verde do WhatsApp (canto inferior direito).

✔ "As fotos não aparecem"
   → Mantenha a pasta assets/img/ (e assets/img/produtos/)
     junto do index.html. No ZIP elas já vêm incluídas.

✔ "Por que suco e chá não têm foto?"
   → Só esses 2 itens não têm foto oficial no iFood. Eles
     usam o emoji do design system (fallback automático).
     Origem das fotos: CREDITS.md.

✔ Outro erro qualquer
   → Mande um print (captura de tela) do erro e em qual versão
     ele acontece (estática ou React) para eu corrigir.

===============================================================
COMO PUBLICAR NA NETLIFY (sem dar 404)
===============================================================
O erro "Página não encontrada (404)" da Netlify acontece porque
a raiz publicada não tinha index.html. Já está corrigido de 3
formas (qualquer uma resolve):

✔ MAIS FÁCIL: arraste o arquivo ceres-brigadeiros-netlify.zip
  em https://app.netlify.com/drop  (o index.html já está na raiz).

✔ Site ligado ao GitHub: o repositório já foi atualizado com o
  arquivo netlify.toml — clique em "Deploys" → "Trigger deploy".

✔ Manual: Site configuration → Build & deploy → Build environment
  → Publish directory = site-estatico

Para publicar a versão React, use no netlify.toml:
  base = "site-react" | command = "npm run build" | publish = "dist"
